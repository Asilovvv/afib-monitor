# Пилот: что где лежит и в каком порядке

| Шаг | Кто | Файл / инструмент |
|---|---|---|
| Протокол | кардиолог, комитет | `PROTOCOL_RU.md` |
| План анализа — **зафиксирован до первого участника** | инженер | `ANALYSIS_PLAN.md` |
| Согласие RU/KY | врач, участник | `CONSENT_RU.md`, `CONSENT_KY.md` |
| Памятка участнику A4 RU/KY | врач | кабинет → Настройки → «Памятка пациенту (A4)» (`/guide?doctor=КОД`) |
| Карта участника, журналы НЯ, отклонений, выдачи, лист соответствия | врач | `CRF_RU.md` (печатать) |
| Датчики: выдача, возврат, электроды, напоминания | врач | кабинет → «Датчики» |
| На визите 2: экспорт данных участника → `P__.json` | врач + участник | приложение → Профиль → «Скачать мои данные» |
| Слепой пакет для кардиолога | инженер | `python tools/pilot_blind.py --exports DIR --visits visits.csv --out OUT` |
| Чтение записей | кардиолог | `READING_GUIDE_RU.md`, `reading_pack.pdf`, `reading_sheet.csv` |
| Расчёт конечных точек | инженер | `python tools/pilot_analyze.py …` → `results.md` |
| Проверка всей цепочки на синтетике (до набора) | инженер | `python tools/pilot_selftest.py` |

Перед первым включением: поставить тег версии кода `git tag pilot-start` (план анализа §1) и не менять приложение
во время пилота, кроме критических исправлений с записью в журнале отклонений.
