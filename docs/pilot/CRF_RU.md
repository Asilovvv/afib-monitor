# Карта участника пилота (CRF)

К протоколу v0.1 и плану анализа v1.0. Одна карта на участника, заполняет врач-исследователь ручкой. **На карте нет
имени и телефона** — только код участника. Соответствие «код — имя — телефон» ведётся на отдельном листе (последняя
страница этого файла), который хранится отдельно, в запираемом шкафу.

---
