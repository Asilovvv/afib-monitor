# Датчик и телефон: от нуля до подключения

Одна страница на весь путь: прошить плату, запитать, поставить приложение, подключить по Bluetooth и понять, что не так,
если телефон датчик не видит. Подробности по каждому шагу — в файлах по ссылкам.

Нужно: CoreS3 SE с припаянным AD8232 (`firmware/README.md`, раздел 1), USB-C **data**-кабель, Mac с папкой `~/afib-flash`,
пауэрбанк или ноутбук **на батарее**, iPhone или Android с приложением, гелевые электроды.

## 1. Прошивка (Mac, 2–3 минуты)

Плата подключена к Mac кабелем:
```bash
curl -fsSL https://raw.githubusercontent.com/Asilovvv/afib-monitor/main/tools/flash_m5.sh | bash
```
Скрипт сам находит порт, скачивает прошивку, собранную GitHub Actions, проверяет её SHA-256 и записывает. Потом один раз
нажать reset (кнопка сбоку). Должно быть: ЭКГ-полоса на экране, вверху **BT WAIT**.

Надпись **BT WAIT / BT PHONE** есть в прошивке начиная с 3 ноября 2026. Если её нет — на плате старая прошивка: прошить заново.

## 2. Питание

Только USB-C от пауэрбанка или от ноутбука, который **не стоит на зарядке**, пока электроды на теле
(`firmware/BENCH_TEST.md`, §0: плата и AD8232 не изолированы от сети). Своей батареи у CoreS3 SE нет.

Некоторые пауэрбанки сами выключаются, когда ток маленький. Признак: экран платы гаснет сам через какое-то время.
Тогда другой пауэрбанк или ноутбук на батарее.

## 3. Приложение

- iPhone: `docs/IPHONE_INSTALL.md`. Бесплатная подпись живёт **7 дней**: если приложение перестало открываться, его
  нужно поставить заново той же командой (данные внутри сохраняются).
- Android: APK из GitHub → Releases → `android-latest`.

## 4. Подключение

1. Открыть приложение → **«Подключить устройство»** → разрешить Bluetooth (спрашивается один раз).
2. Через несколько секунд «Подключаюсь…», потом живая ЭКГ-полоса. Норма — не дольше 15 секунд (`docs/BOARD_DAY.md`, B2).
3. На плате вверху **BT PHONE** зелёным.

Датчик держит **одно** подключение. Пока он подключён к одному телефону (или к ноутбуку), другие его не найдут.

## 5. Проверка связи без телефона (Mac)

Если телефон датчик не находит, сначала понять, чья это проблема — платы или телефона. Закрыть приложение на телефоне
(иначе плата занята) и на Mac:
```bash
cd ~/afib-flash && venv/bin/python ble_check.py --connect 20
```
При первом запуске macOS спросит доступ к Bluetooth для Терминала — разрешить. Скрипт ищет плату 10 секунд, подключается,
читает статус и 20 секунд считает пакеты ЭКГ. Норма: **6,25 ± 0,5 пакета в секунду, потеряно 0**.

- Скрипт нашёл плату и пакеты идут → плата в порядке, дело в телефоне (разрешение Bluetooth, версия приложения,
  7-дневная подпись на iPhone).
- Не нашёл → дело в плате или питании: таблица ниже.

## 6. Если не подключается

Приложение после неудачного поиска само смотрит, что вокруг, и пишет одно из сообщений ниже.

| Что пишет приложение | Что сделать |
|---|---|
| «Bluetooth выключен…» | Включить Bluetooth в Пункте управления, нажать ещё раз |
| «Нет разрешения на Bluetooth…» | Настройки → AFib Monitor → Bluetooth → включить |
| «Телефон не видит ни одного Bluetooth-устройства…» | Выключить и включить Bluetooth; если не помогло — перезагрузить телефон |
| «Датчик не найден…» | Экран платы тёмный — пауэрбанк выключился или кабель отошёл (шаг 2). Вверху **BT PHONE** — плата подключена к другому телефону или ноутбуку: закрыть приложение там или нажать reset на плате. Вверху **BT WAIT**, но не находит — поднести телефон ближе, нажать reset, проверить шагом 5. Надписи BT нет — старая прошивка (шаг 1) |
| «Рядом есть AFib-Monitor со старой прошивкой…» | Шаг 1 |
| «Датчик найден, но подключиться не удалось…» | Поднести телефон ближе, нажать reset на плате, нажать ещё раз |
| Подключается, потом всё время «Связь потеряна, переподключаюсь…» | Расстояние или стены: замерить на экране «Стенд» (Профиль → Устройство), `docs/BOARD_DAY.md`, B3 |
| Приложение на iPhone не открывается | Кончилась 7-дневная подпись: переустановить (`docs/IPHONE_INSTALL.md`, «Переустановка») |

## Что показывает экран платы

| Надпись | Значение |
|---|---|
| **BT WAIT** | Bluetooth включён, плата ждёт телефон |
| **BT PHONE** | Телефон подключён |
| **TAP: 30 S CHECK** | Живая ЭКГ; вердикт даёт только 30-секундная проверка (тап по плашке) |
| **CHECK ELECTRODES** | Электроды отошли или сигнала нет |
| **POOR SIGNAL** | Сигнал упирается в край шкалы, вердикта нет |

Время работы модели в приложении показывается как «≥ 65,5 мс»: в пакете Bluetooth для него 2 байта, а модель на чипе
считает около 73 мс (`docs/BOARD_DAY.md`, A5). Это ограничение формата пакета, а не ошибка замера.
