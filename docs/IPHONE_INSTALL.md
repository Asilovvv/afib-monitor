# Как поставить приложение AFib Monitor на свой iPhone (без App Store)

Приложению нужен Bluetooth, а в Expo Go он не работает. Поэтому приложение собирается на MacBook через Xcode
и ставится на iPhone по кабелю. Бесплатного Apple ID достаточно. Ограничения бесплатного варианта:
- приложение работает **7 дней**, потом его нужно поставить заново той же командой (около 2 минут);
- без пуш-уведомлений с сервера. Локальные напоминания о проверках работают.

Платный аккаунт разработчика ($99 в год) снимает оба ограничения и даёт TestFlight, но для диплома он не нужен.

## Один раз (около часа, в основном загрузка)
1. **Xcode** из App Store (большой, 10+ ГБ). Открыть один раз, согласиться с лицензией и дождаться установки компонентов.
2. Xcode → Settings → **Accounts** → «+» → Apple ID. Появится команда **«(Personal Team)»**.
3. **Node.js** LTS с nodejs.org (установщик .pkg).
4. В Терминале:
   ```bash
   git clone https://github.com/Asilovvv/afib-monitor.git ~/afib-monitor
   cd ~/afib-monitor/mobile && npm ci
   ```
5. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить, перезагрузить.

## Сборка и установка (iPhone подключён кабелем, «Доверять этому компьютеру» — да)
```bash
cd ~/afib-monitor/mobile
npx expo run:ios --device --configuration Release
```
Выбрать свой iPhone в списке. Сборка Release не требует, чтобы Mac был рядом: приложение работает само.

**Если сборка остановилась на подписи (signing):**
1. Открыть в Xcode файл `ios/AFibMonitor.xcworkspace`.
2. Слева выбрать проект, затем вкладка **Signing & Capabilities**:
   - Team = твой «(Personal Team)»;
   - если пишет, что Bundle Identifier занят, поменять на свой, например `kg.asilov.afibmonitor`;
   - если есть строка **Push Notifications**, удалить её крестиком (бесплатная команда её не поддерживает).
3. Запустить команду ещё раз.

**Первый запуск на iPhone:**
1. Настройки → Основные → **VPN и управление устройством** → твой Apple ID → «Доверять».
2. При первом подключении к устройству разрешить приложению Bluetooth.

## Переустановка — раз в 7 дней и после обновлений (около 10 минут)
Бесплатная подпись живёт 7 дней: после этого приложение не открывается, но данные внутри остаются, пока приложение
не удалено. Переустановка поверх старой версии их сохраняет. iPhone подключён кабелем и разблокирован:
```bash
cd ~/afib-monitor && git pull
cd mobile && npm ci
npx expo prebuild -p ios
npx expo run:ios --device --configuration Release
```
`prebuild` без `--clean` дописывает в проект iOS новое (камера для фото тонометра, новые модули), не стирая подпись.
Если Xcode снова спросит Team — выбрать «(Personal Team)», как в первый раз. Если в первый раз Bundle Identifier
меняли на свой, поставить тот же самый: иначе это будет другое приложение, и старые записи в нём не появятся.

## Часть B дня датчика за один заход (B1–B4, около 20 минут)
Нужно: датчик с электродами, iPhone с новой версией, ноутбук **от батареи**.
1. **B1.** Открыть приложение. Bluetooth-разрешение спрашивается один раз — разрешить.
2. **B2.** «Подключить устройство». Засечь время до живой ЭКГ-полосы: норма ≤ 15 с.
3. **B3.** Профиль → Устройство → **Стенд**. Сидеть спокойно 2 минуты, телефон в 1 м от датчика. Сфотографировать
   экран: пакетов в секунду (ожидается 6,25 ± 0,5), потеряно за минуту (ожидается 0), заполненных отсчётов за 30 с (0),
   SNR, батарея, время модели. Потом отнести телефон в соседнюю комнату (около 5 м, через стену) на 1 минуту и
   сфотографировать «потеряно за минуту» ещё раз.
4. **B4.** На том же экране «Записать 60 с сырого сигнала» → «Поделиться» → AirDrop на ноутбук (в папку
   `~/afib-flash`). На ноутбуке:
   ```bash
   cd ~/afib-flash && venv/bin/python afib_stream.py --review ИМЯ_ФАЙЛА.csv
   ```
   SNR в выводе должен совпасть с экраном телефона ± 1 дБ.

Фото и вывод терминала — в чат, цифры впишутся в `docs/BOARD_DAY.md`, часть B.

## Если есть Android
Всё проще: соберу APK-файл (`eas build -p android --profile preview`), его ставишь как обычный файл. Без Mac и без
7-дневного ограничения.
