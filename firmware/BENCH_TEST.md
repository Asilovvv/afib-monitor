# День, когда пришла плата: проверка на столе

Прошивка уже собирается автоматически на GitHub при каждом изменении (Actions → **Firmware**): esp32 core 3.x +
M5Unified + TensorFlow Lite Micro компилируются без ошибок, готовый `.bin` лежит в артефакте `afib-monitor-firmware`.
Значит, в этот день не нужно чинить сборку — только прошить и записать цифры в диплом (места `[TO MEASURE]`).

## 1. Прошить (20 минут)
1. Arduino IDE по разделу 2 README (или скачать `.bin` из GitHub Actions).
2. Upload. На экране: ЭКГ, полоса «собрано N из 32», плашка ритма.
3. ✅ Готово, если без датчика видна плашка **CHECK ELECTRODES**, а не перезагрузка.

## 2. Тот же результат, что в ноутбуке (30 минут)
```bash
python afib_stream.py --port /dev/cu.usbmodem101 --eval --minutes 20 --speed 10
python afib_stream.py --port /dev/cu.usbmodem101 --bench
```
* `--eval` шлёт записи MIT-BIH на чип и считает чувствительность/специфичность **на самом чипе**.
* ✅ Готово, если разница с int8-моделью в ноутбуке ≤ 1 п.п. (те же записи, тот же порог 0,5).
* `--bench`: время одного решения (мс) и свободная RAM → таблица 5.7 диплома.

## 3. Энергопотребление с INA219 (1 час)
* INA219 включается **в разрыв +5 В** питания платы (VIN+ — от источника, VIN− — к плате, общий GND),
  например через USB-переходник с выведенными контактами питания. Читать INA219 удобнее вторым устройством
  или ноутбуком через USB-I²C адаптер, чтобы измеритель не питался от измеряемой линии.
* Замерить 3 режима по 5 минут, записать средний ток и пиковый:
  1. экран включён, BLE подключён, модель работает (обычный режим);
  2. экран выключен, BLE подключён;
  3. модель отключена (только АЦП и BLE) — чтобы увидеть, сколько стоит сама нейросеть.
* Автономность = ёмкость аккумулятора (мА·ч) / средний ток (мА). Записать честно, с указанием режима.
* ⚠️ Схему подключения INA219 стоит один раз проверить по фото/схеме платы, прежде чем включать.

## 4. Живая ЭКГ с AD8232 (30 минут)
1. Электроды по разделу 1 README, сидеть спокойно 5 минут.
2. Сравнить пульс на экране с пульсом по часам / тонометру (± 5 уд/мин).
3. Сохранить 10-секундную ЭКГ из приложения — это рисунок для диплома «сигнал нашего датчика».
4. Подвигать рукой 30 секунд — посмотреть, появляется ли ложная «AFIB» (ожидаемо: да, см. ml/NOISE_SQI.md).

## Что записать в диплом
| Что | Где в дипломе |
|---|---|
| Чувствительность/специфичность на чипе (`--eval`) | 5.7 |

| Фото установки и ЭКГ с AD8232 | 3.2 |
